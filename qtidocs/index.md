# QTIDocs

QTIDocs hosts documentation for open source projects. You keep your docs as Markdown in a `qtidocs/` folder in your GitHub repo, and QTIDocs serves them at `<your-subdomain>.qtidocs.dev`. Every push rebuilds them.

You're reading a QTIDocs site now. These pages live in the [`qtidocs/` folder](https://github.com/quiet-terminal-interactive/qtidocs/tree/main/qtidocs) of the QTIDocs repo.

## What you get

- **Docs that build from your folder structure.** Each `.md` file becomes a page and each directory becomes a nav section. There's nothing to configure.
- **Full-text search, light and dark themes, and syntax highlighting** on every site.
- **[Versioned docs](/versioning):** track several branches or tags, with a version switcher on every page.
- **[PR previews](/previews):** each pull request gets its own live preview.
- **[Analytics](/analytics):** page views, visitors, top pages and referrers. No cookies, and no third-party scripts.
- **[Custom styling](/customizing)** with a single CSS file.
